# soreiisou

ブラウザで遊べるゲーム集です。`index.html`（ゲームセレクト）から遊ぶゲームを選べます。

| ファイル | ゲーム | 人数 |
| --- | --- | --- |
| `soreiisou.html` | それ、言いそう！ | 3〜8人（オンライン） |
| `shimarin-brawl.html` | 大乱交しまりんブラザーズ（Phaser 3） | CPU と最大8人・チーム戦 / オンライン最大8人 |
| `shimarin-party.html` | しまりんブラザーズ パーティー（すごろく＋ミニゲーム8種） | CPU と最大4人 / オンライン最大4人 |
| `fire-station-3d.html` | 消防署さんぽ（PlayCanvas・3D。写真をもとにした消防署と、4階建ての室内を歩きまわる） | 1人 |

## オンラインのしくみ

オンライン対応のゲームはどれも PeerJS（WebRTC）を使い、ルームを作った人（ホスト）のブラウザがサーバー役になります。
ほかの人はホストにだけつながります（STUN / 中継 TURN サーバーの設定も共通）。

- 大乱闘はロックステップ方式です。各プレイヤーが自分の入力をホストへ送り、ホストが全員分をフレームごとにまとめて配ります。
- 対戦中に抜けた人は、全員の画面で同じフレームに「退場」扱いになります。
- パーティーはホストがゲームを進め、画面の状態（と効果音・BGM）を1秒に20回配ります。ほかの人は自分の入力をホストへ送るだけです。途中で抜けた人の枠は CPU が引きつぎます。
- ホストが抜けるとルームは閉じます。

以前の招待リンク（`index.html?room=XXXX`）は、自動で `soreiisou.html` に転送されます。

## 消防署さんぽ（3D）

- `fire-station-3d.html` が本体です。PlayCanvas は `lib/playcanvas.min.mjs`（2.19.7）を import map で読みこみます。
- 建物・車両・家具はすべて箱や円柱の組み合わせで、コードの中で作っています。床や壁の模様（タイル・レンガ・木の板など）はキャンバスで描いたテクスチャ（`T`）。看板の文字は `SIGN_TEXT` で変えられます。
- 主人公は手描きキャラを球・円柱・トーラスで組んだもの（`hero`）。WASD／矢印で移動、Shift で走る、スペースでジャンプ。スマホは左下のスティックとジャンプボタン。
- 外の入口のドアに入ると室内へ（建物の出入りだけは暗転で切りかえ）。
- 室内は B1〜屋上の6フロア（`LEVELS`：B1 倉庫／1F 受付と通信室／2F ショップとトレーニングルーム／3F 談話室／4F 指令室／屋上）を縦に積んだ1つの建物で、全フロアを常に描画しています。手前の壁がない断面（ドールハウス）の見た目で、カメラはキャラの位置（高さも）をなめらかに追いかけます。
- 階の移動は暗転やワープなしで、同じ空間の中を上下するだけです。
  - 階段：部屋の左どなりの折り返し階段を歩いて上り下りします（1フロアで2本、奥に踊り場）。
  - すべり棒：2F〜4F の床の穴に入ると、棒につかまって実際に下へすべります（下りだけ・通る階がそのまま見える）。すべっている間に J（スマホは「降りる」ボタン）を押すと、そのとき通っている階で止まって降ります。押さなければ 1F まで。
- 1F の右の丸い枠には救急車。1F 手前のピンクのマットから外へ出られます。
- 当たり判定は `box()` で置いた箱から自動で作ります（足もとの高さにある箱は通れない・低い箱には乗れる）。見えない壁は `solid()`。1フレームの移動は細かく区切って判定するので、動きが重い端末でも壁をすりぬけません。
- ES モジュールなので GitHub Pages かローカルサーバーで開いてください。
