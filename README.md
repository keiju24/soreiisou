# soreiisou

ブラウザで遊べるゲーム集です。`index.html`（ゲームセレクト）から遊ぶゲームを選べます。

| ファイル | ゲーム | 人数 |
| --- | --- | --- |
| `soreiisou.html` | それ、言いそう！ | 3〜8人（オンライン） |
| `shimarin-brawl.html` | 大乱交しまりんブラザーズ（Phaser 3） | CPU と最大8人・チーム戦 / オンライン最大8人 |
| `shimarin-party.html` | しまりんブラザーズ パーティー（すごろく＋ミニゲーム8種） | CPU と最大4人 / オンライン最大4人 |
| `fire-station-3d.html` | 消防署さんぽ（PlayCanvas・3D。写真をもとにした消防署と、4階建ての室内を歩きまわる） | 1人 |

## オンラインのしくみ

オンライン対応のゲームはどれも PeerJS（WebRTC）を使い、ルームを作った人（ホスト）のブラウザがサーバー役になります。
ほかの人はホストにだけつながります（STUN / 中継 TURN サーバーの設定も共通）。

- 大乱闘はロックステップ方式です。各プレイヤーが自分の入力をホストへ送り、ホストが全員分をフレームごとにまとめて配ります。
- 対戦中に抜けた人は、全員の画面で同じフレームに「退場」扱いになります。
- パーティーはホストがゲームを進め、画面の状態（と効果音・BGM）を1秒に20回配ります。ほかの人は自分の入力をホストへ送るだけです。途中で抜けた人の枠は CPU が引きつぎます。
- ホストが抜けるとルームは閉じます。

以前の招待リンク（`index.html?room=XXXX`）は、自動で `soreiisou.html` に転送されます。

## 消防署さんぽ（3D）

- `fire-station-3d.html` が本体です。PlayCanvas は `lib/playcanvas.min.mjs`（2.19.7）を import map で読みこみます。
- 建物・車両・家具はすべて箱や円柱の組み合わせで、コードの中で作っています。床や壁の模様（タイル・レンガ・木の板など）はキャンバスで描いたテクスチャ（`T`）。看板の文字は `SIGN_TEXT` で変えられます。
- 主人公は手描きキャラを球・円柱・トーラスで組んだもの（`hero`）。WASD／矢印で移動、Shift で走る、スペースでジャンプ。スマホは左下のスティックとジャンプボタン。
- 外の入口のドアに入ると室内へ（建物の出入りだけは暗転で切りかえ）。
- 室内は B1〜屋上の6フロア（`LEVELS`：B1 倉庫／1F 受付と通信室／2F ショップとトレーニングルーム／3F 談話室／4F 指令室／屋上）を縦に積んだ1つの建物で、全フロアを常に描画しています。手前の壁がない断面（ドールハウス）の見た目で、カメラはキャラの位置（高さも）をなめらかに追いかけます。
- 階の移動は暗転やワープなしで、同じ空間の中を上下するだけです。
  - 階段：部屋の左どなりの折り返し階段を歩いて上り下りします（1フロアで2本、奥に踊り場）。
  - すべり棒：2F〜4F の床の穴に入ると、棒につかまって実際に下へすべります（下りだけ・通る階がそのまま見える）。すべっている間に J（スマホは「降りる」ボタン）を押すと、そのとき通っている階で止まって降ります。押さなければ 1F まで。
- 1F の右の丸い枠には救急車。1F 手前のピンクのマットから外へ出られます。
- 当たり判定は `box()` で置いた箱から自動で作ります（足もとの高さにある箱は通れない・低い箱には乗れる）。見えない壁は `solid()`。1フレームの移動は細かく区切って判定するので、動きが重い端末でも壁をすりぬけません。
- ES モジュールなので GitHub Pages かローカルサーバーで開いてください。

## キャラ 3D デバッグ（`debug-kuroneko.html`）

## バトル（`debug-battle.html`）

インポニャンを 妖怪ウォッチバスターズ風の操作感で戦わせる デバッグページ（校庭マップの上）。数値はぜんぶ `data/fwb-skills.json`（威力・クールタイム・攻撃判定の時間・硬直・前に進む量・無敵時間・エフェクトの大きさ／時間 など。書きかえると そのまま反映）。

- 操作：WASD 走る・Shift ダッシュ（走る×1.5）・Q 歩く・J／左クリック A・K X・L Y・U 必殺技・R ロックオン・T 技セット変更・右ドラッグ 視点・ホイール ズーム
- 技：A 三段こうげき（30・30・60、1段 0.42秒・3段目 0.72秒のすばやい連続。続けて押すと次へ、先行入力あり、連打しても はじめから やりなおさない。終わってから 1.2秒のクールタイム）／チャージこうげき（長押し、80〜160、2秒で最大、ため中も ふつうに走れる・ダッシュもできる）／火花の術（長押し、炎の弾 40〜80、射程 5m、ため中も走れる）／回避（2m、無敵 0.05〜0.4秒＋超回避 0.15秒、方向なしは うしろ）／気合いの一発（100、前方 90度）／必殺技（妖気 100%：0.5秒かまえ → 0.6秒から 0.2秒ごとに 10発、前方 240度・4m の広い範囲）。妖気ゲージは 攻撃を当てるとたまり、使うのは 必殺技だけ
- 状態（有限状態機械）：Idle Walk Run Dash / Attack1〜3 / ChargeStart ChargeLoop ChargeAttack / PowerAttack / FireCharge FireAttack / Dodge / SpecialAttack / Damage DamageHeavy Knockback Down GetUp / Dead。攻撃中の自由移動なし、キャンセルできる時間だけ ほかの技・回避
- 攻撃判定：こぶしの骨の位置（＋前方の扇形）。決めた時間だけ有効、同じ攻撃で同じ敵には1回、壁ごしは当たらない。当たったときだけ ヒットストップ（通常 0.04秒・強 0.08秒）とカメラのゆれ。近くの敵へ 軽く向きをなおす
- エフェクト：拳の軌跡（光のかさね）・星形の衝撃・光の粒・衝撃波・地面の輪・オーラ・集中線・砂煙・速度線・残像（モデルのコピー）・アニメ調の炎・強い攻撃で画面が白く光る。使いまわし（オブジェクトプール）。ダメージの数字（太字・黒ふち・ポップして上へ消える、クリティカルは大きく黄色、回復は緑）
- しっぽ・耳・鈴は、アニメの上に ばねで「おくれて ゆれる」動きをたしている
- 右下の技アイコン：クールタイム中は暗く、円で残り時間、使えるようになると光る。チャージの進み、最大で黄色く光る。妖気 100% で必殺技が光る
- 技セット変更（T）：A・必殺技・固有スキル（超回避）は固定、X と Y に チャージこうげき／火花の術／回避／気合いの一発 から 2つ（同じ技は両方に入れられない）。未習得は暗く、習得条件（レベル）が出る。セーブは localStorage の `fwb2.techset.imponyan`。戦闘中は変更できない
- 練習相手：ブスイ人形 3体と、近づくと攻撃してくる「はんげきブスイ」（軽ダメージ・大ダメージ・吹っとばし）。左上のボタン：敵の攻撃 オン／オフ・妖気MAX・HP回復・復活・当たり判定・技セット変更
- 効果音は その場でつくった音（原作の音は使っていない）。必殺技の名前は 原作の技名をそのまま使わず「にくきゅうラッシュ」にしている（`data/fwb-skills.json` で変えられる）

### 攻撃範囲と当たり判定（バトル）

- 長さの基準：データの長さは「身長 1m のキャラ」のときの値で、`global.unit`（インポニャンの身長 1.8m）倍して使う（射程・判定の高さ・前進・吹き飛ばし・回避の距離・飛ぶ速さ）
- 判定の形：前方扇形・円形・球形・前方の長方形・カプセル（拳や飛翔体の通り道）・飛翔体。Hitbox（攻撃）・Hurtbox（攻撃を受ける）・Collider（移動の衝突）を分けている。敵は中心ではなく Hurtbox と重なったら当たり。大ブスイ（ボス）は 頭・胴・うで・足に Hurtbox があり、いくつ重なっても 1ヒットにつき 1回。大きい敵は吹き飛ばない
- 判定の時間は「前のフレームから今までに 有効な時間と重なったか」で決めるので、フレームレートで回数が変わらない。モーションが終わったら判定は のこらない。壁ごしには当たらない
- 三段こうげき：前方扇形（1・2段目 1.2m・80度・高さ 0.1〜1.3m・0.10秒、3段目 1.6m・110度・0.1〜1.5m・0.15秒、吹き飛ばし 0.4m）。チャージ：はなした瞬間に 射程 1.2→1.8m・威力 80→160・前進 0〜0.4m・吹き飛ばし 0〜0.8m（衝撃波もチャージで大きく）。気合いの一発：1.5m・90度・0.15秒・前進 0.4m・吹き飛ばし 0.6m（衝撃波は拳の先から、範囲より大きすぎない）。火花の術：飛翔体（半径 0.2m・8m/秒・射程 5m・敵と壁をつらぬかない、近くの敵の中心へ向きを補正）→ 着弾で円形の爆発 0.6〜1.0m・0.1秒（直撃した敵には重ならない）。回避：2m・向きは変えられない・壁や敵の手前で止まる。必殺技：前方扇形 2m・120度・高さ 0.1〜1.6m・0.08秒×10回、最後だけ 0.8m 吹き飛ばし、発動のときに 地面に 攻撃予定範囲を 少し出す
