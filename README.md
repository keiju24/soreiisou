# soreiisou

ブラウザで遊べるゲーム集です。`index.html`（ゲームセレクト）から遊ぶゲームを選べます。

| ファイル | ゲーム | 人数 |
| --- | --- | --- |
| `soreiisou.html` | それ、言いそう！ | 3〜8人（オンライン） |
| `shimarin-brawl.html` | 大乱交しまりんブラザーズ（Phaser 3） | CPU と最大8人・チーム戦 / オンライン最大8人 |
| `shimarin-party.html` | しまりんブラザーズ パーティー（すごろく＋ミニゲーム8種） | CPU と最大4人 / オンライン最大4人 |
| `fuzei-watch-busters.html` | 風情ウォッチバスターズ（PlayCanvas・3D。制作中：タイトルと2階建て＋屋上の本部） | 1人（オンライン協力は予定） |
| `fire-station-3d.html` | 消防署さんぽ（PlayCanvas・3D。写真をもとにした消防署と、4階建ての室内を歩きまわる） | 1人 |

## オンラインのしくみ

オンライン対応のゲームはどれも PeerJS（WebRTC）を使い、ルームを作った人（ホスト）のブラウザがサーバー役になります。
ほかの人はホストにだけつながります（STUN / 中継 TURN サーバーの設定も共通）。

- 大乱闘はロックステップ方式です。各プレイヤーが自分の入力をホストへ送り、ホストが全員分をフレームごとにまとめて配ります。
- 対戦中に抜けた人は、全員の画面で同じフレームに「退場」扱いになります。
- パーティーはホストがゲームを進め、画面の状態（と効果音・BGM）を1秒に20回配ります。ほかの人は自分の入力をホストへ送るだけです。途中で抜けた人の枠は CPU が引きつぎます。
- ホストが抜けるとルームは閉じます。

以前の招待リンク（`index.html?room=XXXX`）は、自動で `soreiisou.html` に転送されます。

## 消防署さんぽ（3D）

- `fire-station-3d.html` が本体です。PlayCanvas は `lib/playcanvas.min.mjs`（2.19.7）を import map で読みこみます。
- 建物・車両・家具はすべて箱や円柱の組み合わせで、コードの中で作っています。床や壁の模様（タイル・レンガ・木の板など）はキャンバスで描いたテクスチャ（`T`）。看板の文字は `SIGN_TEXT` で変えられます。
- 主人公は手描きキャラを球・円柱・トーラスで組んだもの（`hero`）。WASD／矢印で移動、Shift で走る、スペースでジャンプ。スマホは左下のスティックとジャンプボタン。
- 外の入口のドアに入ると室内へ（建物の出入りだけは暗転で切りかえ）。
- 室内は B1〜屋上の6フロア（`LEVELS`：B1 倉庫／1F 受付と通信室／2F ショップとトレーニングルーム／3F 談話室／4F 指令室／屋上）を縦に積んだ1つの建物で、全フロアを常に描画しています。手前の壁がない断面（ドールハウス）の見た目で、カメラはキャラの位置（高さも）をなめらかに追いかけます。
- 階の移動は暗転やワープなしで、同じ空間の中を上下するだけです。
  - 階段：部屋の左どなりの折り返し階段を歩いて上り下りします（1フロアで2本、奥に踊り場）。
  - すべり棒：2F〜4F の床の穴に入ると、棒につかまって実際に下へすべります（下りだけ・通る階がそのまま見える）。すべっている間に J（スマホは「降りる」ボタン）を押すと、そのとき通っている階で止まって降ります。押さなければ 1F まで。
- 1F の右の丸い枠には救急車。1F 手前のピンクのマットから外へ出られます。
- 当たり判定は `box()` で置いた箱から自動で作ります（足もとの高さにある箱は通れない・低い箱には乗れる）。見えない壁は `solid()`。1フレームの移動は細かく区切って判定するので、動きが重い端末でも壁をすりぬけません。
- ES モジュールなので GitHub Pages かローカルサーバーで開いてください。

## 風情ウォッチバスターズ（制作中）

- `fuzei-watch-busters.html` が本体です（PlayCanvas は `lib/playcanvas.min.mjs`）。キャラの顔の絵はファイルの中に入っています。
- タイトル画面はクリック（Enter）でスタートするだけ。押すと本部（2階建ての消防署＋屋上）に入り、そこから外へは出ません。出動（クエスト本番）はまだ作っていません。
- 本部：1F に受付・工房（職人ヘンリー）・出動用の救急車、2F に指令室（ヘンリー隊長・結成ボード・募集端末）、屋上に朕銭ガシャ。階段は奥の壁ぞいに横向きで、今いる階だけが見えます。
  - 2F → 屋上の階段は、1F → 2F の階段の手前を右から左へのぼります（`S2`。段は板だけなので、2F では下をくぐれます）。
  - 屋上（`buildRoof`）は実在の出張所の写真がもと：さび色の手すり、ホース乾燥塔（`hoseTower`）、足場の枠、室外機。屋上にいるときだけ、空の色・本部の外観（`facade`）・地面・となりの建物を出します。
- 操作：WASD／矢印で移動、Shift で走る、Enter で話す／調べる、1〜4 でスタンプ、Esc で Hu-jo Pad（隊員用端末）。ジャンプはなし。
- なかま・いくせい：左にえらんだ隊員の3Dモデル（メニュー用のカメラで描いて左の枠に写す）と性能。なかまの右は編成サークル（リーダーが上、CPU が左・右・下）で、えらぶと「いれかえ・そうび・いくせい・さくせん・ひかえにもどす」が出る。いれかえは右がリストになり、えらぶと確認が出る。いくせいの右は隊員のリストで、えらぶと朕銭チャージが出て、長押しするほど速くゲージがたまる（途中まで入れた朕銭は `chars[key].xp` に残る）。
- メニューは移動キーで項目をえらび、Enter かクリックで決定（いくせい・そうびの隊員の切りかえは Z / C）。
- 音：本部の BGM `bgm/fwb-hq.mp3`、メニューを開く音 `se/fwb-menu.mp3`、えらぶ音 `se/fwb-move.mp3`、決定の音 `se/fwb-ok.mp3`、もどる・とじる音 `se/fwb-back.mp3`（効果音は頭の無音を削って、WebAudio で先読みして鳴らす）。
- Hu-jo Pad：なかま（メンバー編成：リーダー＋CPU3人・さくせん）、いくせい（朕銭で Lv アップ。Lv99 まで、技は Lv で自動に上がる）、そうび（1人1つ）、もちもの（お助けアイテム・素材・出動セット2つ）、ずかん、マルチ募集、せってい（そうびはメニューにはなく、メンバー編成で隊員をえらんで「そうび」から開く）（音量・画質・カメラ・文字の速さ・隊員名・データの書き出し／読みこみ／消去）。
- 工房：つくる（素材＋朕銭で装備★1〜★3）・きたえる（＋5まで）・アイテムを買う。受付：入隊祝い（最初の1回）と毎日の出勤ボーナス。出動ムービー：「出動!!」で約14秒のムービー（`bgm/fwb-sortie.mp3` の拍に合わせた指令アラート → ポールから救急車へ → エンジン点火・シャッター → 急発進 →「風情バスターズ 出動！！」。はじめは2F指令室：ヘンリー隊長の前に4人が並び、隊長が号令して手をふって見送る。4人は2Fからポール（先に乗る2人）か階段（後の2人）で1Fへ降りて救急車へ（だれがどれかは毎回シャッフル、`mvRoute`）。効果音：ドアの開け閉めは `se/fwb-door-open.mp3`・`se/fwb-door-close.mp3`、ほかは合成（エマージェンシーコール・エンジン始動・サイレン・シャッター・ブースター・発射）。オンラインではホストが出動すると、全員に同じメンバー・同じ乗りこみ方で流れる。Enter / クリックでスキップ。時間は `MVT`）。ヘンリー隊長：出動画面（メンバー4人とミッション。「ミッションをえらぶ」→ 左に内容・右に一覧 → 確認 →「出動!!」。オンラインではホストがミッションを選び、入った人は「準備OK」、全員OKで出動できる）。
- マルチ募集は PeerJS（ほかのゲームと同じ STUN / TURN）。募集を出した人がホストになり、「だれでも」の募集は 20 枠の決まった ID、「合言葉」は4文字のコードで入ります。参加した人は本部に現れて、一緒に歩けます。
- 朕銭ガシャ（屋上）：投入する朕銭（100〜100,000）で「大当たり確率」（0.1%〜100.0%）が変わります。くわしい仕様は `docs/fwb-gacha.md`、確率・ラインナップ・カプセルの色は `data/fwb-gacha.json`（JSON だけ直せば反映）。
  - 大当たり（黒カプセル確定）・中当たり（金・赤）・小当たり（青・灰）の3区分。1回で朕銭と「きょうのガシャ回数」（1日10回）を使います。
  - 最初からいる隊員は4人、ほかの8人はガシャで仲間になります。仲間でない隊員は名簿でシルエットになります。前のセーブは、育てた・装備した・編成に入れた隊員を引きつぎます。
  - 演出は屋上の3Dの機械の前で：前ぶれ（空が暗くなり火の玉）→ カプセルの色が上がる（フェイントあり）→ はねて着地 → 開封とカットイン → キャラは煙が晴れて登場しポーズ／アイテムは煙がすぐ消える → 結果の札。Enter／クリックでとばせます。
- 出動（戦闘）：クエストを受理して 1F の救急車に乗ると出動します。いまは「公園の矢の雨」（風情公園）のマップだけ。ほかの場所は同じしくみで増やせます（`startSortie` / `buildPark` / `PARK_GROUPS`）。
  - 風情公園：南の入口 → 噴水の広場 → 西に遊具（砂場・すべり台・ブランコ・ジャングルジム）、東に池と東屋 → 北の生け垣の門 → 大きな木（しめ縄）と石灯籠のボスの広場。
  - 4人で出動（編成のリーダー＝自分、ほかは CPU）。役割（アタッカー・タンク・レンジャー・ヒーラー）ごとに、通常攻撃（3連）・スキル2つ・必殺技（ゲージ満タンでカットイン）が変わります（`ROLE_ACT`）。わざの名前は各キャラの moves。
  - 操作：WASD 移動・J／左クリック こうげき・K（右クリック）スキル1・L スキル2・U 必殺技・Space 回避（無敵あり）・1/2 出動セットのアイテム・E 調べる／長押しで仲間を起こす・Esc ポーズ（Q でリタイア）。
  - ザコのブスイ：ポイスッテ（紙くずを投げる）・ミニバーサーカー（群れで殴りに来る）。倒すと素材を落とします。
  - ボス：ブスイに取りつかれた恵授。近づくと逃げる、扇の矢、影縫い（当たると遅くなる）、矢の雨（赤い円の予告）、HP 半分から天穿つ一矢（赤い線の予告）。広場に入ると門が閉じてボス戦。
  - CPU：近くの敵をねらい、レンジャー・ヒーラーは間合いをとる、ヒーラーは回復、ダウンした仲間を起こしに行く、予告の円から逃げる。さくせん（Hu-jo Pad）で動きが少し変わります。
  - ミッション：メイン（ボスを正気にもどす）、サブ（ブスイを15体：＋500朕銭／キラキラを3つ調べる）。制限時間 8 分。全員ダウンか時間切れで失敗（拾った素材は持ち帰れる）。
  - クリアで報酬の朕銭とボスの素材。ずかんに記録され、受理中のクエストは終わります。スマホの操作ボタンはまだありません。
  - ブスイは群れごとにかくれていて、近づくとけむりと一緒にあらわれます（`btEncounter`）。
  - ミニミッション：ときどき時間つきのおだい（ブスイを4体・ノーダメージ・スキル3回・キラキラ）が出て、成功で＋300朕銭と★2素材（`MM_TYPES`）。
  - ボスのブレイク：こうげきでブレイクゲージがたまると「BREAK!」で4秒動けなくなり、ダメージ1.5倍。HP 30% を切ると、いかりモード（赤いもや・攻撃が速い）。
  - CPU の仲間はふきだしでしゃべります（出現・スキル・起こす・ブレイクなど）。ダウンすると「たすけて〜！」。足もとに役割の色の輪（リーダーは黄色）。
  - リザルトにクリアランク（S〜C：タイム・ダウン数・ミニミッション・サブミッションで決まる）。
- ダッシュ（Shift）：本部でも出動中でも、操作中のキャラの左横に6区切りの丸いゲージが出ます（`STAM` / `stamTick` / `stamDraw`）。ダッシュ中は 1.1 秒ごとに1区切りへり、空になると満タンにもどるまでダッシュできません（ゲージが赤くなる）。やめて 0.6 秒たつと 1区切り 0.5 秒で回復し、満タンになると消えます。
- キャラの見た目：12人とも体つき・服・帽子・背中の物がちがいます（`LOOK`）。顔は写真のステッカーのまま。
  - 例：ホムラ＝赤い上着と炎の肩あて・マフラー、バーサーカー＝大きな体と毛皮・トゲの肩、NA・GATA＝ヘルメットとベスト、しまりん＝むらさきのローブとフード、ヘンリー＝ジャージとはちまき、こうたん＝えんび服とシルクハット、恵授＝マントとフード・矢筒、今井＝ボーダーとセーラー帽・長ぐつ、朕太＝金の上着とマント・王冠、いちご＝はかまと葉っぱの髪かざり、うんこいちご＝ローブとうずまき帽子、Kenshin＝つなぎとゴーグル・アンテナつきの背負い物。
- ごうせい・しんか（Hu-jo Pad）：
  - 合成：★素材3つ → 1つ上の★、アイテムどうし（おにぎり3つ → 特製カレー など）、★3素材2つ＋★2素材4つ → 「進化の玉」（`RECIPES` / `matUpRecipes`）。材料が中央に吸いこまれて光る演出。
  - 進化：Lv30 ＋ 進化の玉 ＋ 3,000朕銭。名前と必殺技が変わり（`EVO`）、能力 1.2 倍、背中に光る輪と胸のしるしがつきます。進化の玉はガシャ（大当たり・中当たり）とボスのクリア報酬（30%）からも出ます。
- セーブは localStorage（`fwb.save.v2`。仲間は `own`、ガシャの回数は `gacha`、きょうの回数は `gday`）。
- デモプレイ用：せっていの「朕銭（デモ用）」が「むげん」（いまは最初から「むげん」）のあいだは朕銭がへらず、表示は ∞ になります。本当の朕銭は別にとってあり、セーブにもそちらを書くので、「ふつう」にもどせば元の朕銭にもどります。
