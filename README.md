# soreiisou

ブラウザで遊べるゲーム集です。`index.html`（ゲームセレクト）から遊ぶゲームを選べます。

| ファイル | ゲーム | 人数 |
| --- | --- | --- |
| `soreiisou.html` | それ、言いそう！ | 3〜8人（オンライン） |
| `shimarin-brawl.html` | 大乱交しまりんブラザーズ（Phaser 3） | CPU と最大8人・チーム戦 / オンライン最大8人 |
| `chinta-legend.html` | 朕太の伝説 〜狂戦士の城〜（Three.js・3D。章ごとに公開、いまは第1章） | 1人 |
| `fire-station-3d.html` | 消防署さんぽ（PlayCanvas・3D。写真をもとにした消防署と、4階建ての室内を歩きまわる） | 1人 |

## オンラインのしくみ

どちらのゲームも PeerJS（WebRTC）を使い、ルームを作った人（ホスト）のブラウザがサーバー役になります。
ほかの人はホストにだけつながります（STUN / 中継 TURN サーバーの設定も共通）。

- 大乱闘はロックステップ方式です。各プレイヤーが自分の入力をホストへ送り、ホストが全員分をフレームごとにまとめて配ります。
- 対戦中に抜けた人は、全員の画面で同じフレームに「退場」扱いになります。
- ホストが抜けるとルームは閉じます。

以前の招待リンク（`index.html?room=XXXX`）は、自動で `soreiisou.html` に転送されます。

## 朕太の伝説（3D）

- `chinta-legend.html` が本体です。Three.js は `lib/three.module.min.js`（r170）、ブルームなどの後処理は `lib/addons/`（Three.js 付属のもの）を使います。
- メニューで「高画質／軽量」を切り替えられます（スマホは最初から軽量）。
- 顔画像と朕太の声は、しまりんブラザーズと同じものを `chinta-assets.js` にまとめています。
- 効果音は `se/` のものを使います。ES モジュールを使うので、ファイルを直接開くのではなく GitHub Pages かローカルサーバーで開いてください。
- 通貨は「朕銭」と「響晶」。敵の落とし物は `DROPS`、アイテムは `ITEMS` で決めます。持ち物・クリア状況・開けた宝箱はブラウザの localStorage（`chinta3d`）に保存します。
- 章は `CHAPTERS` に並んでいます。新しい章を出すときは `ready: true` にして、その章のマップと敵を足します。

## 消防署さんぽ（3D）

- `fire-station-3d.html` が本体です。PlayCanvas は `lib/playcanvas.min.mjs`（2.19.7）を import map で読みこみます。
- 建物・車両・家具はすべて箱や円柱の組み合わせで、コードの中で作っています。看板の文字は `SIGN_TEXT` で変えられます。
- 主人公は手描きキャラを球・円柱・トーラスで組んだもの（`hero`）。WASD／矢印で移動、Shift で走る、スペースでジャンプ。スマホは左下のスティックとジャンプボタン。
- 外の入口のドアに入ると室内へ。室内は4フロア（1F 受付と通信室／2F ショップとトレーニングルーム／3F 談話室／4F 指令室）で、外観から離れた場所（`OX`）に `FH` ずつ積んであり、表示するのは今いる階だけです。
- 階段：左手前の上り階段をのぼりきると上の階へ、となりの下り階段を下りきると下の階へ（暗転して切りかえ）。
- すべり棒：2〜4階の床の丸い穴に入ると、すべり降ります（下りだけ）。すべっている間に J（スマホは「降りる」ボタン）を押すと、そのとき通っている階で降ります。押さなければ1階まで。
- 1階の右の丸い枠には救急車。1階の入口のピンクのマットから外へ出られます。
- 当たり判定は `box()` で置いた箱から自動で作ります（足もとの高さにある箱は通れない・低い箱には乗れる）。見えない壁は `solid()`。
- ES モジュールなので GitHub Pages かローカルサーバーで開いてください。
