# 効果音（se/）

## 効果音ラボ（https://soundeffect-lab.info/）
利用規約により、ゲームに組みこんで使うのは自由（クレジット任意）。**この音だけを取り出して配ったり、ほかの素材集に入れたりするのは禁止**です。

| blade1〜5 | 刀で斬る（katana-slash1〜5） |

| sheath1 | 刀を納める（katana-storage1） |
| dash1 | 高速移動（highspeed-movement1） |
