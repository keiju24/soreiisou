# 朕銭ガシャ 仕様書（風情ウォッチバスターズ）

投入した朕銭の量で「大当たり確率」が変わるガシャです。
朕銭を温存して低い確率で回すか、たくさん投入して確実に狙うか、を選べます。

- 本体：作り直し中（前の版の `fuzei-watch-busters.html` は消しました。この設定と仕様は新しい版でも使います）
- 設定：`data/fwb-gacha.json`（確率・ラインナップ・カプセルの色）
- 場所：本部の屋上の機械（Enter で調べると画面が開く）

---

## 1. 大当たり確率の計算式

```
rate(%) = minRate + (maxRate − minRate) × ((投入量 − min) ÷ (max − min)) ^ exponent
```

| 設定 | 値 | 意味 |
| --- | --- | --- |
| `invest.min` | 100 | 投入できる最小の朕銭 |
| `invest.max` | 100,000 | 投入できる最大の朕銭 |
| `jackpotCurve.minRate` | 0.1 | 最小投入のときの確率（%） |
| `jackpotCurve.maxRate` | 100.0 | 最大投入のときの確率（%） |
| `jackpotCurve.exponent` | 0.85 | 曲線の形。500 投入でちょうど 1.0% になるように決めた値 |

- 計算結果は小数第1位で四捨五入し、**画面に出ている数字のまま抽選**します（見た目と中身を一致させる）。
- 指数が 1 より小さいので、少しの投入でも確率が上がり、たくさん入れるほど上がり方が一定に近づきます。

| 投入量 | 大当たり | 中当たり | 小当たり |
| --- | --- | --- | --- |
| 100 | 0.1% | 25.0% | 74.9% |
| 500 | 1.0% | 24.8% | 74.2% |
| 1,000 | 1.9% | 24.5% | 73.6% |
| 3,000 | 5.0% | 23.8% | 71.2% |
| 5,000 | 7.8% | 23.1% | 69.1% |
| 10,000 | 14.1% | 21.5% | 64.4% |
| 30,000 | 35.9% | 16.0% | 48.1% |
| 50,000 | 55.5% | 11.1% | 33.4% |
| 100,000 | 100.0% | 0.0% | 0.0% |

コード：`jackpotRate(amt)` と `tierRates(amt)`。

```js
function jackpotRate(amt) {
  const I = GDATA.invest, C = GDATA.jackpotCurve;
  const x = Math.max(0, Math.min(1, (amt - I.min) / (I.max - I.min)));
  return Math.round((C.minRate + (C.maxRate - C.minRate) * Math.pow(x, C.exponent)) * 10) / 10;
}
// [小当たり, 中当たり, 大当たり]（%）
function tierRates(amt) {
  const j = jackpotRate(amt), r = Math.round((100 - j) * GDATA.rareShare * 10) / 10;
  return [Math.max(0, Math.round((100 - j - r) * 10) / 10), r, j];
}
```

投入量は、スライダーと ◀▶ で次のきざみで動きます（`invest.steps`）。
100〜1,000 は 100 ずつ、〜5,000 は 500 ずつ、〜20,000 は 1,000 ずつ、〜100,000 は 5,000 ずつ。
「最小」ボタンと「MAX」ボタン（Y キー。持っている朕銭で入れられる最大）もあります。

## 2. 抽選テーブル

1. 0〜100 の乱数をひき、`大当たり確率` 未満なら **大当たり**。
2. 次の `(100 − 大当たり) × rareShare`（初期値 25%）の範囲なら **中当たり**。
3. 残りは **小当たり**。
4. 決まった区分の `capsules` から、カプセルの色を重みで選ぶ。
5. 決まった区分の `pool` から、景品を重みで選ぶ（まだ仲間でないキャラは `newCharBonus` 倍で出やすい）。

| 区分 | カプセル | 主な景品 |
| --- | --- | --- |
| 大当たり（jackpot） | 黒（確定） | ★3 の隊員（ヘンリー・こうたんご主人様・恵授・朕太）、アシストフィギュア×3 |
| 中当たり（rare） | 金・赤 | ★2 の隊員、最初の4人、目覚まし時計・ゲージあめ、★3 素材 |
| 小当たり（normal） | 青・灰 | おにぎりなどのお助けアイテム、★1・★2 素材 |

- すでに仲間のキャラが出たら、区分ごとの `duplicate.lv` だけ Lv が上がります（Lv99 なら `coinsIfMax` の朕銭）。
- 1回まわすと、投入した朕銭と「きょうのガシャ回数」（`dailyLimit`、初期値 10）を1つ使います。デモ用の朕銭むげん中は回数を数えません。

コード：`gcRoll(amt)`。

## 3. 演出とステートの流れ

```
idle（投入・確率変動）
  └ Enter ─→ crank（ハンドル）─→ eject（カプセル排出・色の示唆）─→ open（開封・カットイン）─→ result（獲得報酬）
                                                                                     └ Enter ─→ idle
```

| フェーズ | 内容 | コード |
| --- | --- | --- |
| 1 投入・確率変動 | 投入量を変えると「大当たり確率 X.X%」の数字がなめらかに増減し、ポンと弾む | `SCREENS.gacha` / `gcLoop` |
| 前ぶれ | 区分ごとの `omen` の確率で、空が暗くなり、機械から火の玉が立ちのぼる（大当たりは必ず。ほかはフェイント） | `gaOmen` |
| 2 排出・カプセル色 | カプセルが転がり出る。決まった色より下の色で出てきて、ゆれるたびに色が上がることがある（灰→青→赤→金→黒）。色が変わらないフェイントもある（`fakeUpgradeChance`）。**黒が出たら大当たり確定**。大当たりは 3 割の確率で最初から黒で出る | `capSeq` / `gaUpdate` |
| 3 開封・リザルト | カプセルが大きくはねて着地 → 割れて白く光る → ななめの帯のカットイン（`cutin`：「大当たり！！」「中当たり！」「小当たり」）→ キャラは煙が晴れて登場しポーズ、アイテムは煙がすぐ消える → 結果の札 | `gaCutin` / `gaShowResult` |

演出中は Enter／クリックで最後までとばせます。

## 4. データ構造（`data/fwb-gacha.json`）

```jsonc
{
  "version": 1,
  "invest": { "min": 100, "max": 100000, "steps": [[1000, 100], [5000, 500], [20000, 1000], [100000, 5000]] },
  "jackpotCurve": { "minRate": 0.1, "maxRate": 100.0, "exponent": 0.85 },
  "rareShare": 0.25,          // 大当たりに漏れた残りのうち、中当たりになる割合
  "dailyLimit": 10,           // 1日に回せる回数
  "newCharBonus": 2,          // まだ仲間でないキャラの重みの倍率
  "capsules": {               // rank が大きいほど期待度が高い
    "gray":  { "name": "灰色", "rank": 0, "hex": "#9aa0a6" },
    "black": { "name": "黒色", "rank": 4, "hex": "#1b1519", "glow": "#b23cff" }
  },
  "fakeUpgradeChance": 0.5,
  "tiers": {
    "jackpot": {
      "label": "大当たり", "cutin": "大当たり！！", "color": "#ffd84a",
      "omen": 1.0,                                    // 前ぶれが出る確率
      "capsules": [{ "color": "black", "weight": 1 }],
      "duplicate": { "lv": 10, "coinsIfMax": 1000 },
      "pool": [
        { "type": "char", "id": "henry", "weight": 10 },
        { "type": "item", "id": "assist", "count": 3, "weight": 4 }
      ]
    },
    "rare":   { "…": "同じ形" },
    "normal": { "…": "同じ形" }
  }
}
```

`pool` の `type`：

| type | 項目 | 内容 |
| --- | --- | --- |
| `char` | `id` | 隊員（`CREW` の key） |
| `item` | `id`, `count` | お助けアイテム（`ITEMS` の key） |
| `mat` | `id`, `count` | 決まった素材（`MATS` の id） |
| `matRandom` | `rarity`, `count` | ランダムなブスイの素材（★1〜★3） |

確率・ラインナップ・色を変えるときは、この JSON だけ直せば反映されます（コードの変更は不要）。
JSON は `fetch` で読むので、GitHub Pages かローカルサーバーで開いてください。
